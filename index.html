How I work

From first call to production support

The same six stages on every product I've owned. The last one is the reason the others matter.

01

Discovery & architecture

Understand the domain and its constraints, model the data, draw the service boundaries, and choose a stack the team can still maintain in two years.

02

Contracts first

Types and API contracts before screens. TypeScript end to end, REST or GraphQL defined up front, so frontend and backend can move in parallel.

03

Build

React and Next.js interfaces, Node and NestJS services, React Native where mobile is needed, and AI pipelines wired in as first-class features.

04

Harden

Jest, Vitest and React Testing Library on the units, Playwright end to end, plus auth, permissions and the edge cases nobody demos.

05

Ship

Dockerised services, GitHub Actions pipelines, AWS infrastructure, staged rollouts — deployment as a routine event, not a Friday night.

06

Operate

Monitoring, performance work, cost control and production support. I stay on the product after launch, which is where most of the real learning is.
